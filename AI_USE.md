# AI use log

This file is the running record of where and how AI tools were used in this project.

**Tools used so far:** Claude (Anthropic), running in Claude Code: model Claude Fable 5.2 for research,
design, review and documentation, and Claude Opus 5.5 subagents for most of the code.

## Summary for the project page (keep this paragraph current)

> We used Claude (Anthropic) in Claude Code as an engineering assistant: to research NISAR data access before
> the event and to write the data-processing pipeline, the web application and the documentation. No images, video or audio in the project are AI-generated: every picture is real satellite data or a diagram drawn in code. AI-written code is acknowledged in the data manifest (`generator.ai_assisted`) and in a metadata tag on every exported raster.
